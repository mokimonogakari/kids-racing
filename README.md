# ぶーぶーレース グランプリ

グランプリ版：5台の動物カートと **同時スタート** で本気の競争をします。順位バッジ・追い抜き・スピードメーターつき。ゴール順でメダル（1位 金／2位 銀／3位 銅／4位以降 完走リボン）がもらえ、表彰台に並びます。負けることもあるけれど、最後まで走れば必ず褒めてくれて、シールももらえます。コースごとのベストタイムと最高順位を記録します。

音声改善：短い案内を優先し、任意の応援を読み上げ待ちにためません。案内中はBGMと効果音を下げ、同じ内容を字幕でも表示。「よーい」と「どん」は実際のスタートに合わせます。音声の声質は端末の日本語音声に依存します。

スマホ改善版：画面下の大きな左右ボタンを押し続けて操作できます。画面左右を触る従来の操作も使えます。星を5個集めるごとに短い加速が発生します。「Ⅱ」で休けい、「つづける」で再開。アプリ切替時も一時停止して入力を解除します。

**あそぶ:** https://mokimonogakari.github.io/kids-racing/

ちいさなこども（3〜5さいくらい）のための、**本気で競争する** レースゲームです。
スマートフォンのブラウザで、ゆびで さわるだけで あそべます。字が読めなくても、絵と音と声で わかるように作っています。

- 6つののりもの：あかいくるま／しょうぼうしゃ／バス／パトカー／きゅうきゅうしゃ／きょうりゅうカー
- 3つのコース：はらっぱ（うしさんが道をわたる）／うみ（くじらさんがざぶーん）／ゆきやま（ゆきだるまさんがてをふる）
- 5台のライバル：くまさん／うさぎさん／かえるさん／ぶたさん／ねこさん が動物カートで同時スタート。追い抜けば「ぬいた！」、抜かれれば「おいかけろー！」と声がかかります。
- 1レースは約60〜90秒。ころんだり、止まったりすることはありません。負けることもあるけれど、ゴールすれば順位に応じたメダルとシールがもらえ、4位以降でも「さいごまで はしった！ えらい！」と褒めてくれます。
- ライバルには「追いつき補正」があり、大きく引き離されても近くに戻ってくるので、いつも接戦になります。
- 絵はすべて Canvas 2D / SVG で描画、音はすべて WebAudio で合成しています（画像・音声ファイルのダウンロードなし、外部ライブラリなし、ビルド不要）。
- 広告・外部リンク・データ送信はありません。シール・記録・設定は端末の localStorage にだけ保存されます。

## あそびかた

1. みどりの ▶ ボタンをタップ。
2. 「どれに のる？」— すきなのりものをタップ（のりものの音がなります）。
3. 「どこを はしる？」— コースの絵をタップ。
4. 「よーい、どん！」— スタートライトが赤から緑に変わると、車は自動で走ります。**画面下の左右ボタンを押し続ける（または画面の左がわ・右がわをさわる）** と、そちらに曲がります。
   - 画面上部のバーで、ゴールの旗までの のこりと、ライバル5台のいる場所が わかります。
   - 画面上の丸いバッジが いまの順位（1い〜6い）。順位が変わると光ります。
   - 右下のスピードメーターで はやさが わかります。にじいろの道や星5個の加速中は赤く光ります。
   - ⭐ やくだものに さわると「キラーン」とあつまります（上に数とアイコンで表示）。星が5こたまると「びゅーん！」と加速。
   - にじいろの道（やじるし）にのると「びゅーん！」とはやくなります。ライバルを抜くチャンスです（「ふつう」「つよい」ではライバルも使います）。
   - ライバルの真後ろにぴったりつくとスリップストリームで少しはやくなります。
   - 赤白の縁石（えんせき）にのると「ダダダ」と画面がゆれます（対応端末では振動も）。
   - どうぶつや ボール、ライバルに ぶつかっても、ぽよーんと はねるだけ。道からはみだしても少しゆっくりになるだけです。
   - まんなか下の ピンクのボタンで クラクション。どうぶつたちが ジャンプします。
5. ゴール！ 順位に応じたメダル（1位 金／2位 銀／3位 銅／4位以降 完走リボン）とシールがもらえ、表彰台に上位3台が並びます。タイムと順位がコースごとのベストなら「しんきろく！」。
   - みどりのボタン（くるっとやじるし）＝もういっかい
   - あおいボタン（くるま）＝ほかののりもの
6. タイトルの ピンクの本のボタンで「シールブック」が見られます（あつめたシールは保存されます）。

## おうちのかたへ（設定）

画面右上の小さな歯車を **2秒間ながおし** すると設定がひらきます（こどもが間違えて開かないようにしています）。設定中はゲームが一時停止します。

| 項目 | 内容 |
| --- | --- |
| こうかおん | クラクション・チャイム・エンジン音等の効果音 ON/OFF |
| おんがく | BGM ON/OFF |
| こえ | 音声ガイド（speechSynthesis, ja-JP）ON/OFF。端末に日本語音声がない場合は何も読み上げません |
| かたむけて ハンドル | 端末の傾きで操作（初期値 OFF。iPhone では ON にしたときに許可ダイアログが出ます）。タッチ操作も常に使えます |
| スピード | のんびり（初期値）／ふつう |
| きょうそう | ライバルの つよさ。やさしい＝ライバルが遅めで子どもが勝ちやすい／ふつう（初期値）＝接戦／つよい＝星と にじいろの道を使わないと勝てません。どの設定でも「追いつき補正」が働き、大きく離されても近くに戻ってくるので いつも接戦になります |
| タイトルへ もどる | レースをやめてタイトルへ |
| シールを ぜんぶ けす | シールブックの記録を消去（確認あり） |

アプリがバックグラウンドになると自動で一時停止します。

## ローカルで動かす

ES Modules と Service Worker を使うため、`file://` ではなく HTTP サーバーで開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をスマートフォン（同じWi-Fi）やPCのブラウザで開く
```

開発用 URL パラメータ：

- `?fast=1` … とても短いコース（動作確認用）
- `?seed=123` … コースの乱数シードを固定
- `?nosw=1` … Service Worker を登録しない

## テスト

Node.js 20 以上で、依存パッケージなしで動きます。

```sh
node --test          # コース生成・当たり判定/バウンド・進行度・ライバルAI/順位・レース全体・音声文言・記録・シールブック保存（モックストレージ）・設定
npm run check        # すべての JS を node --check
```

ブラウザでの通し検証（Playwright + Chrome でタイトル→レース→ゴール→シールブック→設定を実際に操作し、各画面のスクリーンショットを保存します）：

```sh
node tools/verify.mjs
# PW_MODULE=/path/to/node_modules/playwright/index.mjs CHROME=/path/to/chrome node tools/verify.mjs
```

アイコン（`icons/*.png`）は `icons/icon.svg` から Playwright で生成しています：

```sh
PW_MODULE=/path/to/node_modules/playwright/index.mjs node tools/make-icons.mjs
```

## GitHub Pages で公開する

1. このリポジトリを GitHub に push します。
2. GitHub の **Settings → Pages → Build and deployment → Source: 「GitHub Actions」** を選びます。
3. `main` ブランチ（または `claude/**` ブランチ）に push すると `.github/workflows/pages.yml` が動き、自動で公開されます（Actions タブから手動実行も可能）。
4. 公開された URL をスマートフォンで開き、「ホーム画面に追加」するとアプリのように全画面で遊べます（オフラインでも動きます）。

## ファイル構成

```
index.html              画面（タイトル／のりもの／コース／レース／ゴール・表彰台／シールブック／設定）
css/style.css           レイアウト（縦・横どちらも対応、セーフエリア対応）
js/main.js              画面遷移・入力・ゲームループ・設定・保存
js/race.js              レースのルール（DOMなし）：順位・追い抜き・スリップストリーム
js/ai.js                ライバルの運転（レーン選び・障害物回避・追いつき補正・難易度）
js/course.js            コース生成（純粋なデータ）：カーブ標識・観客席・コーンも配置
js/physics.js           移動・バウンド・進行度などの計算（純粋関数）
js/render.js            疑似3Dの道路描画・ライバル・パーティクル・カメラ演出
js/render-hud.js        順位バッジ・スピードメーター・位置バー・スタートライト・ポップ文字
js/art.js               のりもの・動物カート・どうぶつ・景色などの絵（Canvas 2D）
js/art-track.js         カーブ標識・観客席・コーン・タイヤ壁・旗ふり係の絵
js/art-medals.js        メダル・リボン・トロフィーの絵（ゴール画面とシール）
js/audio.js             WebAudio による効果音とBGM（すべて合成）
js/audio-engine.js      ギア付きエンジン音・風切り音
js/audio-sfx.js         スキッド・縁石・追い抜き・歓声・ゴールのジングル
js/voice.js             音声ガイド（speechSynthesis）
js/voice-lines.js       音声の文言と、順位・追い抜きのアナウンス制御
js/records.js           コースごとのベストタイム・最高順位の保存
js/stickers.js          シールブック（メダルシールを含む）
js/settings.js / storage.js  設定と安全な localStorage 操作
sw.js                   Service Worker（HTML/JS/CSS はネットワーク優先、バージョン付きキャッシュ）
manifest.webmanifest    PWA マニフェスト
icons/                  オリジナルのアイコン（SVG と PNG）
tests/                  node --test 用テスト
tools/make-icons.mjs    アイコン生成スクリプト
tools/verify.mjs        Playwright + Chrome でのレース通し検証とスクリーンショット
```

キャラクター・のりもの・音楽はすべてこのゲームのためのオリジナルです。
