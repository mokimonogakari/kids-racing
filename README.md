# ぶーぶーレース

**あそぶ:** https://mokimonogakari.github.io/kids-racing/

ちいさなこども（3〜5さいくらい）のための、**まけない** レースゲームです。
スマートフォンのブラウザで、ゆびで さわるだけで あそべます。字が読めなくても、絵と音と声で わかるように作っています。

- 6つののりもの：あかいくるま／しょうぼうしゃ／バス／パトカー／きゅうきゅうしゃ／きょうりゅうカー
- 3つのコース：はらっぱ（うしさんが道をわたる）／うみ（くじらさんがざぶーん）／ゆきやま（ゆきだるまさんがてをふる）
- 1レースは約60〜90秒。ころんだり、まけたりすることはありません。ゴールすると全員「1い」のメダルとはなかんむり、シールがもらえます。
- 絵はすべて Canvas 2D / SVG で描画、音はすべて WebAudio で合成しています（画像・音声ファイルのダウンロードなし、外部ライブラリなし、ビルド不要）。
- 広告・外部リンク・データ送信はありません。シールの記録と設定は端末の localStorage にだけ保存されます。

## あそびかた

1. みどりの ▶ ボタンをタップ。
2. 「どれに のる？」— すきなのりものをタップ（のりものの音がなります）。
3. 「どこを はしる？」— コースの絵をタップ。
4. 「よーい、どん！」— 車は自動で走ります。**画面の左がわ・右がわをさわる（または指をすべらせる）** と、そちらに曲がります。
   - ⭐ やくだものに さわると「キラーン」とあつまります（上に数とアイコンで表示）。
   - にじいろの道（やじるし）にのると「びゅーん！」とはやくなります。
   - どうぶつや ボールに ぶつかっても、ぽよーんと はねるだけ。道からはみだしても少しゆっくりになるだけです。
   - まんなか下の ピンクのボタンで クラクション。どうぶつたちが ジャンプします。
   - いちばん上のバーで、ゴールの旗までの のこりが わかります。
5. ゴール！ メダルとシールがもらえます。
   - みどりのボタン（くるっとやじるし）＝もういっかい
   - あおいボタン（くるま）＝ほかののりもの
6. タイトルの ピンクの本のボタンで「シールブック」が見られます（あつめたシールは保存されます）。

## おうちのかたへ（設定）

画面右上の小さな歯車を **2秒間ながおし** すると設定がひらきます（こどもが間違えて開かないようにしています）。設定中はゲームが一時停止します。

| 項目 | 内容 |
| --- | --- |
| こうかおん | クラクション・チャイム等の効果音 ON/OFF |
| おんがく | BGM ON/OFF |
| こえ | 音声ガイド（speechSynthesis, ja-JP）ON/OFF。端末に日本語音声がない場合は何も読み上げません |
| かたむけて ハンドル | 端末の傾きで操作（初期値 OFF。iPhone では ON にしたときに許可ダイアログが出ます）。タッチ操作も常に使えます |
| スピード | のんびり（初期値）／ふつう |
| タイトルへ もどる | レースをやめてタイトルへ |
| シールを ぜんぶ けす | シールブックの記録を消去（確認あり） |

アプリがバックグラウンドになると自動で一時停止します。

## ローカルで動かす

ES Modules と Service Worker を使うため、`file://` ではなく HTTP サーバーで開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をスマートフォン（同じWi-Fi）やPCのブラウザで開く
```

開発用 URL パラメータ：

- `?fast=1` … とても短いコース（動作確認用）
- `?seed=123` … コースの乱数シードを固定
- `?nosw=1` … Service Worker を登録しない

## テスト

Node.js 20 以上で、依存パッケージなしで動きます。

```sh
node --test          # コース生成・当たり判定/バウンド・進行度・レース全体・シールブック保存（モックストレージ）・設定
npm run check        # すべての JS を node --check
```

アイコン（`icons/*.png`）は `icons/icon.svg` から Playwright で生成しています：

```sh
PW_MODULE=/path/to/node_modules/playwright/index.mjs node tools/make-icons.mjs
```

## GitHub Pages で公開する

1. このリポジトリを GitHub に push します。
2. GitHub の **Settings → Pages → Build and deployment → Source: 「GitHub Actions」** を選びます。
3. `main` ブランチ（または `claude/**` ブランチ）に push すると `.github/workflows/pages.yml` が動き、自動で公開されます（Actions タブから手動実行も可能）。
4. 公開された URL をスマートフォンで開き、「ホーム画面に追加」するとアプリのように全画面で遊べます（オフラインでも動きます）。

## ファイル構成

```
index.html              画面（タイトル／のりもの／コース／レース／ゴール／シールブック／設定）
css/style.css           レイアウト（縦・横どちらも対応、セーフエリア対応）
js/main.js              画面遷移・入力・ゲームループ・設定・保存
js/race.js              レースのルール（DOMなし）
js/course.js            コース生成（純粋なデータ）
js/physics.js           移動・バウンド・進行度などの計算（純粋関数）
js/render.js            疑似3Dの道路描画・HUD・パーティクル
js/art.js               のりもの・どうぶつ・景色などの絵（Canvas 2D）
js/audio.js             WebAudio による効果音とBGM（すべて合成）
js/voice.js             音声ガイド（speechSynthesis）
js/stickers.js          シールブック
js/settings.js / storage.js  設定と安全な localStorage 操作
sw.js                   Service Worker（HTML/JS/CSS はネットワーク優先、バージョン付きキャッシュ）
manifest.webmanifest    PWA マニフェスト
icons/                  オリジナルのアイコン（SVG と PNG）
tests/                  node --test 用テスト
tools/make-icons.mjs    アイコン生成スクリプト
```

キャラクター・のりもの・音楽はすべてこのゲームのためのオリジナルです。
